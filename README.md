# Пси-база

Общедоступная база знаний о психических расстройствах: что известно, насколько
это доказано, чего мы не знаем. Собирается из исследований, не из мнений.

**Статус:** каркас. Наполнения ещё нет — сначала структура, правила и проверки.

## Что здесь есть

| Папка | Что лежит |
|---|---|
| `sources/` | карточки источников: PMID/DOI, язык, тип исследования, что именно взято |
| `topics/` | темы: определение, числа, эффекты, противоречия, пробелы |
| `for-app/` | следствия для приложения «Опора» — если теме есть практическое применение |
| `docs/` | правила приёма и схема данных |
| `tools/` | проверки, без зависимостей |

## Четыре правила, без которых это не база

1. **Пункт без источника — не пункт.** Источник открыт, проверен, PMID/DOI
   сверен, а не взят по памяти.
2. **У каждого числа — уровень доказательности.** Мета-анализ, РКИ, когорта,
   обзор, гайд, мнение. Рядом стоящие «мета-анализ 40 работ» и «блог
   психолога» без уровня выглядят одинаково убедительно — и это делает базу
   вредной.
3. **Расхождения показываются, а не сглаживаются.** Если два источника дают
   разные числа, в тексте оба.
4. **Раздел «не нашёл» обязателен.** Названный пробел — не дырка в работе,
   а результат.

Подробно — [`docs/rules.md`](docs/rules.md).

## Два языка

Русский — канон. Английский — перевод, лежит рядом (`ru.md` / `en.md`).
Правка одного без другого роняет проверку `npm run check`: она сравнивает
между парами заголовки, числа, PMID, DOI и ссылки — то, что не зависит от
языка. Стиль она не проверяет, молчаливые потери фактов — проверяет.

## Чего здесь нет и не будет

- диагностики и «проверь себя» без пометки «не заменяет врача»;
- лечебных обещаний;
- перепечатанных абстрактов: факт формулируется своими словами, ссылка — на
  источник;
- рейтингов «какое лекарство лучше».

## Запуск проверок

```bash
node tools/parity.mjs        # паритет RU/EN по всем темам
node tools/parity.mjs паника # одна тема по слагу
```

Зависимостей нет: нужен только Node.
