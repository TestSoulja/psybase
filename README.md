# Пси-база

Общедоступная база знаний о психических расстройствах: что известно, насколько
это доказано и чего мы пока не знаем. Собирается из исследований, а не из
мнений и не из пересказов.

> База не заменяет врача, не ставит диагноз и не назначает лечение.
> Если жизни или здоровью угрожает опасность — **112**.

## Что это

Справочник, а не руководство к действию. Утверждение здесь стоит ровно
столько, сколько стоит источник под ним: у каждого числа назван тип
исследования, у каждой темы есть раздел о том, чего не хватает.

## Для кого

Для человека с диагнозом, его близких, студента, врача, журналиста — для
любого, кто хочет проверить утверждение о психике, а не поверить на слово.
Входа «для пациента» и «для специалиста» нет: текст один. Мы исходим из того,
что читать его будут с обеих сторон, и пишем так, чтобы обе могли.

## Что внутри темы

- **Что это** — определение и границы: где заканчивается расстройство.
- **Что известно** — числа и эффекты, каждый с источником и уровнем
  доказательности.
- **Что не доказано** — где источники расходятся и почему: выборки, годы,
  критерии.
- **Не нашёл** — что искали и не нашли; сюда же попадают источники, которые
  не открылись.
- **Источники** — карточки: PMID/DOI, язык оригинала, тип исследования, год
  и что именно из него взято.

## Как читать уровень доказательности

| Уровень | Что за ним стоит |
|---|---|
| `meta` | систематический обзор, мета-анализ |
| `rct` | рандомизированное контролируемое исследование |
| `cohort` / `case` | когорта, случай-контроль, наблюдение |
| `review` | обзор без метаанализа, консенсус, гайд |
| `opinion` | экспертное мнение, редакционная статья |
| `unsure` | тип определить не удалось — и это видно читателю |

Если тип определить нельзя, это пишется прямо, а не прячется: ровный тон без
уровня и есть то, что делает базу опасной.

## Почему «не нашёл» — тоже ответ

В каждой теме есть раздел «Не нашёл», и он не может быть пустым: если
нашлось всё, значит искали недостаточно. Отсутствие данных — это результат
исследования, а не пробел в работе. Источник, который не открылся, тоже
попадает туда: пересказывать недоступное по памяти мы не будем.

## Чего здесь нет и не будет

- диагностики и «проверь себя» с подсчётом баллов;
- лечебных обещаний и советов «что делать именно вам»;
- перепечатанных абстрактов: факт формулируется своими словами, ссылка ведёт
  на источник;
- рейтингов «какое лекарство лучше»;
- пересказа источников, которые не удалось открыть.

## В каком состоянии база

Каркас готов: правила приёма, схема данных, проверки, которые падают, если
правило нарушено. Тем ещё нет: ни одна ещё не сконвертирована. Дату запуска
не обещаем: непроверенная цифра в тексте — ровно то, против чего эта база
построена.

## Два языка

Русский — канон, английский — перевод, лежит рядом. В карточке источника
помечается язык оригинала: английские числа нельзя переносить на русские
формулировки как на эквивалент. Такой перенос допускается только с пометкой
«не проверено».

## Лицензии и как ссылаться

Текст — **CC BY 4.0**, карточки источников — **CC0**, код — **MIT**.
Что под какой и что можно — [`LICENSES/README.md`](LICENSES/README.md).

Ссылаться можно так: «Пси-база, TestSoulja, CC BY 4.0».
Лицензия не даёт прав на чужие статьи: мы ссылаемся, а не копируем.

## Нашли ошибку

Issue в этом репозитории — про текст и источники: число не сходится с
источником, ссылка не открывается, утверждение звучит как обещание лечения,
формулировка стигматизирует при верном факте.

Это не канал поддержки: личные истории и вопросы «что со мной» здесь не
разбирают, и отвечаем не сразу. Если плохо прямо сейчас — 112, а не Issue;
в неэкстренном случае — служба психологической помощи в вашем регионе.

Правим текст, а не спорим: факт важнее тона, но и тон — часть факта.

## Для тех, кто ведёт базу

| Папка | Что лежит |
|---|---|
| `sources/` | карточки источников: PMID/DOI, язык, тип исследования, что взято |
| `topics/` | темы: определение, числа, эффекты, противоречия, пробелы |
| `for-app/` | следствия для приложения «Опора» — на сайт не публикуется |
| `docs/` | правила приёма и схема данных |
| `tools/` | проверки и сборка, без зависимостей |

Четыре правила, без которых это не база:

1. пункт без источника — не пункт: источник открыт, PMID/DOI сверен, а не
   взят по памяти;
2. у каждого числа — уровень доказательности;
3. расхождения показываются, а не сглаживаются;
4. раздел «не нашёл» обязателен.

Подробно — [`docs/rules.md`](docs/rules.md). Где остановились — [`STATUS.md`](STATUS.md),
читается первым. Что в этой среде не открывается — [`docs/env.md`](docs/env.md).

Зависимостей нет: нужен только Node.

```bash
npm run check                # паритет RU/EN + STATUS.md: очереди, даты, «Не нашёл»
node tools/parity.mjs паника # одна тема по слагу
```

### Сборка сайта и выкладка

```bash
node tools/build.mjs             # dist/: адреса /ru/<slug>/ и /en/<slug>/
node tools/build.mjs --fixture   # только topics/_example, во временную папку
scripts/deploy-pages.ps1         # выкладка в gh-pages — по слову владельца
```

Сайт: <https://testsoulja.github.io/psybase/>. Адрес задаётся одной константой
`BASE` в `tools/build.mjs`; локально открывать `dist/index.html` напрямую нельзя —
ссылки абсолютные, нужен любой статический сервер с этим префиксом.

В `dist/` попадают только темы из `topics/`. `for-app/` на сайт не публикуется;
темы с `draft: true` пропускаются, и в логе сборки написано, что именно
пропущено. На каждой странице — дисклеймер «не заменяет врача» и 112,
«обновлено», уровни доказательности бейджами, отдельный блок «Не нашёл» и
источники со ссылками на PMID/DOI. Markdown экранируется целиком, сырой HTML не
проходит. Пары нет — сборка падает; «Не нашёл» нет — сборка тоже падает.

Стили лежат одним файлом `dist/style.css` и кешируются браузером: на страницу
приходятся только разметка и текст. У каждой страницы есть `canonical` и
`alternate hreflang` на оба языка (плюс `x-default` → русская версия), `<html
lang>` проставлен. Для печати — отдельные правила: прячется навигация, ссылки и
рамки становятся чёрными, таблицы не рвутся по строкам.

В ветке `gh-pages` лежит только содержимое `dist/` плюс `.nojekyll`; история
только дописывается. Force-push запрещён, и `scripts/deploy-pages.ps1` этого не
делает: если ветка ушла вперёд, скрипт падает. Перед выкладкой он требует чистое
дерево, `npm run check` с exit 0 и успешную сборку.
