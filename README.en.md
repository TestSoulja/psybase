# Psy-base

A public knowledge base on mental disorders: what is known, how strong the
evidence is, and what nobody knows yet. Built from research, not opinions.

It does not replace a doctor, does not diagnose and does not prescribe.
If life or health is in danger — **112**.

The Russian text is canonical: a topic exists when `ru.md` exists; English
files are translations kept next to it. Site: <https://testsoulja.github.io/psybase/>.
