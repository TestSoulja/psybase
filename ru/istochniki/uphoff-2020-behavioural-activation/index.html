аннотация

Абстракт открыт 25.11.2026 через NCBI eutils, PMID сверен Europe PMC (hitCount 1). Полный текст Cochrane — 403, все числа из абстракта.

Уверенность авторов: умеренная для сравнения с обычным лечением и КПТ, низкая для остальных сравнений. Ключевая оговорка, которую нельзя терять: разница с обычным лечением не выдерживает анализа по худшему сценарию — то есть «работает» подтверждено, «работает у всех» нет.
