# Исследовать — цикл волн до остановки

Ты оркестратор, сам почти не ищешь. Цикл: волна → интеграция → коммит → push →
следующая.

1. **Очередь** — `research/queue.md`. Пополняется в этом порядке: (а) `next` из
   файлов направлений; (б) «Не нашёл» в `topics/*/ru.md`; (в) состояния, которых
   в базе нет; (г) вопросы из только что сконвертированных тем. Очередь исчерпана —
   стоп, а не повод выдумывать направления.
2. **Волна:** до 20 субагентов, каждому 10 минут. Направление или пункт очереди —
   один агент.
3. **Сдача** обязательна даже при остановке по времени: `research/<дата>/<файл>.md`
   с front-matter `lane / status / next / updated`; дописывание — разделом
   `## Заход N`, файлы не переписывать. Внутри: `### Что нашёл` (утверждение одной
   строкой — число, год, популяция — id — уровень — чем читал), `### Журнал
   запросов` (дословно, индекс, сколько вернулось), `### Где расхождения`,
   `### Не открылось`, `### Не нашёл`.
4. **Сверка id.** Перед проверкой — `node tools/sources-index.mjs <id>`; проверять
   только то, чего нет. PMID — Europe PMC `EXT_ID:<id> AND SRC:MED`, hitCount 1
   (503 → NCBI eutils, пометить); DOI — `doi.org/api/handles`, responseCode 1.
   Пакетами по 40. «По памяти» запрещено. DOI со скобками сверять полной строкой.
5. **После волны** (только оркестратор): `research/README.md` и `research/queue.md`,
   один пакетный проход по новым id, один коммит, сразу push. В README — строка
   журнала: номер волны, +утверждений, +id, время.
6. **Перед следующей волной:** `npm run check` и `node tools/status.mjs`. Красное —
   стоп и отчёт, а не «продолжу, потом починю».
7. **Стопы:** слово «стоп» или `0Стоп0`; файл `research/.stop` (проверять перед
   каждой волной); три волны подряд без новых утверждений; красная проверка;
   пустая очередь.
8. **Запрещено:** конвертировать темы, править `topics/`, `sources/`, `legacy/`,
   сайт и стражей.
9. Разрешений не спрашивать. Отчёт — одной строкой после каждой волны, без
   остановки цикла.

## Экономия

- Агент читает front-matter и хвост файла (последние ~120 строк), тело не листает.
- Одно утверждение — одна строка `- `, до 240 знаков; абзацы — только в «Не нашёл».
- Перед запросом — grep по «Журнал запросов»; перед записью — grep по id.
- Кап: 60 утверждений и 25 КБ прироста на файл за волну.
- Закрытые двери — `research/env-holes.md`, в файле строка «см. env-holes».
- TSV не пишется руками: `node tools/research-stats.mjs --tsv claims.tsv`.
- Отчёт агента — 5 строк: направление, +утверждений, +id, что не открылось, next.
