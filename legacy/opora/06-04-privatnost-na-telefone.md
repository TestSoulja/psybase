# 6.4 Приватность на телефоне

| Механизм | От чего защищает | Чего не даёт |
|---|---|---|
| PIN-гейт в PWA (JS) | случайного взгляда, «дали телефон ребёнку» | чтения `localStorage`, devtools, бэкапа, root. OWASP прямо пишет: локальная аутентификация обходится локальным пользователем |
| Нейтральное имя и иконка | узнавания по подписи на домашнем экране | истории, «часто посещаемых», поиска по телефону |
| Шифрование AES-GCM с ключом из пароля | чтения файла, бэкапа, чужого профиля | подбора слабого PIN (10⁴ вариантов), скриншота открытого экрана |
| Локскрин телефона | всего, если код знает только владелец | партнёра, знающего код; превью на заблокированном экране |
| Быстрый выход | взгляда в следующий момент | истории, «недавних», кэша, скачанного файла |
| FLAG_SECURE / скрытие в «Недавних» | скриншотов и превью | **в PWA недоступно** — только в нативном приложении; на iOS скриншоты не блокируются вообще |

**Что видно другому человеку:** иконка и подпись; история браузера и подсказки
адресной строки; **снимок экрана в переключателе приложений делает ОС, не
приложение**; скриншоты в галерее и облаке; файл экспорта в «Загрузках»
(имя остаётся в списке даже после удаления); выученные слова клавиатуры и
буфер обмена; Screen Time / «Цифровое благополучие».

**Что советуют организации, работающие с людьми в небезопасной среде:**
считать устройство потенциально под наблюдением; быстрый выход — отраслевой
стандарт; удаление истории само по себе заметно и не является защитой; общий
аккаунт и облако — отдельный канал утечки; не обещать «полной приватности»,
а планировать безопасность вместе с человеком.

**Риски экспорта:** файл открытым текстом, без пароля; имя файла и папка
«Загрузки» видны после удаления приложения; уезжает в облачную синхронизацию;
пересылка создаёт копии у третьих лиц; чужой взгляд на сырой текст — риск
эмоциональный, не только технический.

**Что делать у нас, по приоритету и стоимости:**

1. Экран «чего это приложение не защищает» при первом запуске — дёшево.
2. Быстрый выход: нейтральная страница, замена записи в истории — дёшево.
3. Блокировка по `visibilitychange` + PIN с подписью «от взгляда, не от
   специалиста» — дёшево (**и это не шифрование**).
4. Нейтральные `name` и иконка в манифесте — дёшево.
5. Настоящее шифрование at rest (AES-GCM + PBKDF2, парольная фраза) — дорого,
   с предупреждением о потере данных.
6. Экспорт только по подтверждению с текстом рисков, имя файла без слов
   «терапия», «психика» — дёшево.
7. Ноль сети, аналитики и чужих шрифтов — уже есть, закреплено тестом.

**Прямой вывод по PIN:** это замок от случайного взгляда, а не защита. Честная
подпись рядом с ним обязательна, иначе приложение обещает то, чего не даёт.
