## Как читать

- Нужен ответ на один вопрос («можно ли PIN?», «что говорить близкому?») —
  открывать файл направления, а не читать всё.
- В каждом направлении есть честная граница: раздел «не нашёл» или прямо
  названный пробел. **Пункт без ссылки не считается фактом.**
- Ссылки на источники стоят внутри файла, рядом с утверждением, а не в конце.
