# 6.28 Цифровые вмешательства 2024–2026

Что нового и что доказано. Только PubMed-записи, открытые 25.11.2026; числа — из абстрактов, год — из записи PubMed.
## ФАКТ

**1. Главный мета-анализ по ПРЛ (2024).** 40 публикаций, 38 вмешательств, 6611 участников, 32 РКИ.
g Хеджеса: паранойя **−0,52** (−0,86…−0,18), суицидальные идеи **−0,13** (−0,25…−0,01),
общая тяжесть ПРЛ **−0,17** (−0,42…0,10) — **не значимо**. Мишени: идеи 17/38 (45 %),
тяжесть ПРЛ 4/38 (11 %), селфхарм 5/38 (13 %); ДБТ-подход 8/38. → [1]

**2. Человеческое сопровождение прибавки не дало.** Дословно: «степень человеческой поддержки
не была связана с эффектом». Значит схемы «приложение + телефонный контакт > только приложение»
по ПРЛ **никто не подтвердил** — связь искали и не нашли. → [1]
Родственное (102 РКИ, 19 758 человек, депрессия): общий g = −0,56, сопровождение не помогало
при мягких симптомах, но взаимодействие «сопровождение × тяжесть» есть — при тяжёлых полезнее. → [6]

**3. Удержание, измеренное (2026, 79 РКИ).** Запуск приложения 92,4 %, приверженность 61,8 %,
отсев к концу лечения **18,6 %**, к катамнезу **28,4 %** (интервалы предсказания очень широкие). → [2]

**4. ДБТ-приложение, РКИ n = 576 (переедание).** 6 недель против листа ожидания: приступы
IRR **0,69**, психопатология **d = −0,68**. Но **отсев 48 %**, вовлечённость падала по ходу. → [3]

**5. Приложения осознанности (70 РКИ, 9258 человек).** Взвешенный отсев **24,7 %**; в крупных
исследованиях (n ≥ 100 на группу) — **38,7 %**. → [5]

**6. Дневник в приложении vs бумажные карточки в ДБТ (ПРЛ, n = 78).** Приложение: +37,1 дня
в лечении, +3,16 навыка в неделю. Но по QALY выигрывала **бумага** (скорр. разница **−0,054**),
и по тяжести депрессии тоже. Приложение удобнее — не эффективнее. → [7]

**7. Самомониторинг сам не лечит (2025, ECoWeB-PREVENT, n = 558).** Использование дневника
и «инструментов» **не** предсказывало изменение депрессии (все p > 0,05). Предсказывали только
задания по активации поведения (β = −0,28) — через них шёл эффект КПТ-приложения. → [8]

**8. Маленькие РКИ завышают.** «Wise Eating» (ДБТ-мини-программа, n = 101, 4 недели, контроль —
психообразование): **d = 1,07** по перееданию, но регуляция эмоций, импульсивность, депрессия,
тревога — незначимы. → [4]

**Контекст:** ДБТ против СИОЗС при ПРЛ (РКИ, n = 84) снижает суицидальные события и селфхарм за 6 мес., к 12 мес. группы сравниваются. → [9]

## ВЫВОД

- Цифровое ДБТ работает **слабо и узко**: эффект есть по суицидальным идеям и паранойе,
  по общей тяжести ПРЛ — нет. Это не замена терапии и не «лечение ПРЛ».
- Эффект дают **действия**, а не запись: дневник без привязанного навыка в данных не отличается
  от нуля [7][8].
- Главная проблема продукта — **отсев 25–48 %** [3][5], а не набор функций.

## Что это меняет для «Опоры»

1. **Не рассчитывать на симптоматический эффект.** Потолок для соло-приложения без терапевта —
   g ≈ 0,1–0,2 по идеям, ≈ 0 по общей тяжести (это максимум для класса продуктов [1]).
   «Станет легче» в описании — непроверяемое обещание.
2. **Удержание важнее фич.** 48 % отсева у приложения с доказанным эффектом и поддержкой
   исследователей [3]. Метрика номер один — возврат на 7-й и 30-й день, не число экранов.
3. **Каждая запись кончается действием** — навык, микрошаг, «что сделаю сейчас» [7][8].
4. **Честная формулировка:** «блокнот навыков и состояний в телефоне; не терапия и не замена
   специалисту». Никаких заявлений про снижение риска суицида — измеряли только идеи.

## ПРОБЕЛ (не доказано)

- **Перенос в жизнь.** Все исходы — самоотчёты; поведенческих или внешних измерений нет.
- **Суицидальные исходы.** Максимум — идеи, g = −0,13 [1]; попыток, госпитализаций, смертей нет.
- **Долгосрочность.** Катамнез в мета-анализе не выделен; у ДБТ эффект к 12 мес. исчезает [9]; у приложений данных за 6+ мес. почти нет.
- **Активный контроль.** Большинство сравнений — с листом ожидания; против психообразования
  эффект падает (см. d = 1,07 на n = 101 [4]).
- **Вред.** Систематических данных о вреде (ухудшение, зависимость от самоконтроля, руминация
  от дневников) за 2024–2026 не нашёл. Косвенно: приложение-дневник не лучше бумаги по QALY [7],
  самомониторинг не даёт эффекта [8] — это «не помогает», а не «вредит». Ни вред, ни его
  отсутствие утверждать нельзя.

## НЕ НАШЁЛ

- РКИ ДБТ-приложения в популяции ПРЛ с исходами «попытка / селфхарм» — таких записей нет.
- Прямого сравнения «приложение + телефонный контакт» против «только приложение» при ПРЛ.
- Мета-анализа вреда цифрового самонаблюдения при ПРЛ (руминация, трекинг как компульсия).
- Cochrane-обзора по цифровым вмешательствам при расстройствах личности.
- NICE/WHO 2024–2026 именно по цифровым вмешательствам при ПРЛ (в PubMed не встретились,
  сайты вручную не проверял).
