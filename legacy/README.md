  на общую тяжесть — ноль.

- Алекситимия при ПРЛ: **71,3 %**. Диссоциация: **72,5 %**. ПТСР: **53 %**.
  РПП: **30 %**. Депрессия: **71–83 %**.
- Мета-анализ предупреждений о триггерах: помогают **нет**, тревогу ожидания
  повышают.
- Психологический дебрифинг: 11 РКИ, пользы нет, в одном — риск выше (OR 2,88).
- Электронный дневник: соблюдение **94 %** против **11 %** у бумажного.
