# Беременность и лактация
Обновлено: 2026-11-25. Спринт: сырьё, не текст для базы.

## Что нашёл

- Подтверждённых утверждений с числом — **0**. Ни один PMID/DOI не сверен по абстракту в этой сессии: успел только поиск (Europe PMC, выдача 4 запросов), до чтения абстрактов и до `doi.org/api/handles` время кончилось. По правилу 1 такие кандидаты в «Что нашёл» не переносятся; они лежат в «Не дошёл до» как очередь, а не как факты.

## Где расхождения

- Пока нечего сопоставлять: ни одного источника не прочитано. Предварительно (по названиям, без чисел и без права цитировать): по перинатальной депрессии выдача забита страновыми обзорами (Эфиопия, Индия, Южная Азия, Китай), а не многоцентровыми оценками — при переносе в базу это даст ложную «глобальную» цифру. То же по послеродовой депрессии: часть обзоров считает «вероятную» депрессию по шкалам, часть — по диагностическому интервью (PMID 40224605), и эти доли несравнимы. Разделять при чтении, иначе получится ровно та ошибка, от которой предупреждает правило 2.

## Не открылось

- `https://www.nice.org.uk/guidance/cg192` — не запрашивал в этой сессии; по `docs/env.md` отдаёт 403, поэтому формулировки NICE в файле отсутствуют.
- `https://www.nice.org.uk/guidance/cg45` — то же: 403, не читал.
- Полные тексты по антидепрессантам в беременности (NEJM, BMJ, JAMA) — платный доступ, абстракты не открывал; чисел из них нет и не будет без открытого источника.

## Не нашёл

- Не нашёл ни одного **открытого** пересчёта «абсолютный риск пороков на 1000 беременностей» при СИОЗС: в выдаче только относительные оценки (OR/HR) в названиях. Без открытого текста абсолютные и относительные риски не разделить — не записываю ничего.
- Не нашёл в выдаче ни одного источника по **проникновению препаратов в грудное молоко** с числом (milk-to-plasma ratio, relative infant dose): запрос по лактации не выполнялся — время.
- Не нашёл регистровых работ Nordic по антидепрессантам в беременности: запрос не выполнялся.

## Не дошёл до —

- Чтение абстрактов всех 7 кандидатов выше (`resultType=core`), извлечение чисел с годом и популяцией, различение абсолютного и относительного риска.
- Перинатальная депрессия: доля по диагностическому интервью, отдельно антенатальная и постнатальная.
- Нелеченая депрессия и исходы: преждевременные роды, низкий вес при рождении — где эффект депрессии, а где препарата.
- Антидепрессанты в беременности: пороки (абсолютный риск на 1000), преэклампсия, неонатальный адаптационный синдром, персистирующая лёгочная гипертензия новорождённого.
- Лактация: проникновение в молоко (relative infant dose), что известно по сертралину/пароксетину против флуоксетина.
- Nordic registers: запрос по `AUTH`/`TITLE` для датских, шведских, норвежских регистровых когорт не выполнялся.
- Проверка DOI через `doi.org/api/handles` — ни одного не проверял.
- Расхождения «депрессия vs препарат»: не начато, потому что все ключевые работы по этой развилке ещё не прочитаны.
