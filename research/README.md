Здесь лежит сырьё: что искали, что нашли, что не открылось. Это **не** темы для

## Как возобновлять (не начинать с поиска)

1. Найти направление в таблице ниже.
2. Прочитать front-matter его файла: `status`, `next`, `lane`.
3. Перед каждым запросом — `node tools/sources-index.mjs <PMID|DOI>`: если
   источник уже проверен (есть карточка в `sources/`), брать из карточки.
4. Дописывать в «## Журнал запросов» дословную строку запроса, индекс и сколько
   вернулось. Следующий заход начинается с `next`, а не с нового поиска.

```bash
node tools/sources-index.mjs          # все идентификаторы: где упомянут, проверен ли
node tools/sources-index.mjs 35048835 # один
```

## Формат файла направления

```markdown
---
lane: 3
status: сдан | остановлен по времени
next: "с чего продолжать: конкретный запрос или источник"
updated: 2026-11-25
---

## Что нашёл
- <утверждение> — <число>, <год>, <популяция> — <PMID/DOI/URL> — <тип>

## Где расхождения
## Не открылось
## Не нашёл
## Журнал запросов
- Europe PMC — `<дословная строка запроса>` — вернулось 12, отобрано 4
## Не дошёл до —
```

`status: сдан` ставится только тогда, когда «Не дошёл до» пуст или объяснён;
иначе — `остановлен по времени`.

## Для следующей волны

Правило то же: каждый агент берёт свой файл и его `next`, дописывает **тот же
файл** разделом `## Заход 5 (ГГГГ-ММ-ДД)`, обновляет `status` и `next`. Индекс
обновляет только тот, кто собирает волну, — субагенты в него не пишут.

Настройки запуска одной волны сохранены командой `.opencode/command/issledovat.md`
(слово «Исследовать»): список 19 файлов, шаблон задачи, сверка id и этот же
стоп-условие. Команда запускает ровно одну волну и сама себя не повторяет.

### Условие остановки волн

Волны прекращаются, когда выполнено **любое** из двух:

- волна дала **меньше 20 новых утверждений** (считать по файлам до и после, а не
  по словам агентов);
- все оставшиеся `next` упираются в **403 или платный доступ** — то есть
  следующая волна не может ничего добавить без браузера или денег.

Сверх этого правила волны остановлены **решением владельца** 25.11.2026: волна 4
дала 125 утверждений, объёмный критерий не сработал, но следующий шаг — не пятая
волна, а конвертация. После остановки работа идёт не в `research/`, а в `topics/`:
сырьё переезжает в темы. Возобновлять волны можно только по слову владельца —
иначе спринт бесконечно переписывает одно и то же.
