# Среда: что работает, а что нет

Замерено 25.11.2026 с этой машины (Windows, PowerShell). Нужен, чтобы каждая
новая сессия не тратила полчаса на те же 403.

## Работает

| Инструмент | Как | Зачем |
|---|---|---|
| **Europe PMC REST** | `https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=EXT_ID:<pmid>%20AND%20SRC:MED&format=json&resultType=lite` | сверка PMID без браузера |
| то же по DOI | `query=DOI:%22<doi>%22` | DOI → автор, год, название |
| то же по PMC | `query=PMCID:PMC<число>` | полный текст в PMC |
| **doi.org handle API** | `https://doi.org/api/handles/<doi>` | `responseCode: 1` = DOI существует; отдаёт целевой URL |
| WHO, NIMH, NHS | обычный `curl` | страницы и фактшиты открываются |
| `raw.githubusercontent.com` | обычный `curl` | проверка живого файла в репозитории |
| `minzdrav.gov.ru` | `curl -A "Mozilla/5.0 ..."` → 200; без User-Agent — таймаут (000) | сайт Минздрава; замерено 25.11.2026 |
| `pravo.gov.ru`, `publication.pravo.gov.ru` | **только HTTP** → 200; HTTPS — таймаут | тексты актов; замерено 25.11.2026 |
| `icdcdn.who.int` | обычный `curl` → 200, `print-ICD-11-MMS-en.zip` 8 279 465 байт | текст МКБ-11 (MMS, release 2025-01) читается; замерено 25.11.2026 |
| **NCBI eutils** `esummary.fcgi?db=pubmed&retmode=json&id=…` | обычный `curl` → 200, отдаёт `title`/`pubdate` по PMID, cookie не нужен | обходной путь сверки PMID, когда Europe PMC лежит; замерено 25.11.2026 на 8 номерах |

## Не работает и почему

| Источник | Код | Что это значит |
|---|---|---|
| `pubmed.ncbi.nlm.nih.gov/<id>/` | пустая страница «Cookies must be enabled» | нужен браузер; для сверки хватает Europe PMC |
| `nice.org.uk` (CG78, CG113, CG142, NG222, NG225) | **403** на HTML, PDF и через прокси | формулировки NICE цитировать нельзя, пока их не откроет человек или браузер |
| `psychiatry.org` (DSM-5-TR) | **403** | критерии DSM сверять по первоисточнику нельзя, только по вторичным описаниям с пометкой |
| `psychiatryonline.org` | **403** | полные тексты APA Journals закрыты, работа только по абстрактам |
| `jamanetwork.com` | **403** | JAMA и архивы — только абстракты |
| SAGE Journals (`journals.sagepub.com`) | **403** | BAP и часть британских журналов — только абстракты |
| Wiley (обзор NG225) | 403 | то же |
| `iris.who.int` (bitstream CDDR 2024) | обрыв `curl: (56)` на 16 368 байтах, куски по 256 КБ обрываются на ~12 КБ | CDDR не скачивается: диапазонный запрос `0-0` даёт 206, файл — нет. МКБ-11 брать с `icdcdn.who.int`, CDDR — с другого хоста |
| `pypdf` на скачанных PDF | падает `negative seek value` | часть PDF не парсится, нужен другой инструмент |

## Ловушки, на которых уже теряли время

1. **DOI с круглыми скобками обрезается регуляркой.** `10.1016/S0140-6736(17)32802-7`
   при шаблоне `[^\s)\]]+` превращается в `10.1016/s0140-6736(17` и «не находится».
   проверять полную строку, а не обрезанную. Затронуло 4 из 194 идентификаторов;
   проверка через `doi.org` подтвердила, что все они настоящие.
2. **PMID по памяти — чужой PMID.** Два «вспомненных» номера оказались статьями
   про алкоголь и инсульт. Всегда сверять.
3. **`git` пишет прогресс в stderr**, и PowerShell с `$ErrorActionPreference='Stop'`
   считает это падением. Судить по `$LASTEXITCODE`.
4. **Файлы с BOM** ломают разбор front-matter и ссылок. Снимать `\uFEFF` в начале.
5. **443 работает, 22 может не работать** — SSH к VPS проверять отдельно, не
   считать «сервер лежит» по таймауту SSH.
6. **Госсайты РФ смотрят на User-Agent.** `curl https://minzdrav.gov.ru` без
   заголовка отдаёт `000` (таймаут), с `-A "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"`
   — `200` и реальный текст (замерено 25.11.2026). `Invoke-WebRequest` тоже
   открывает без пляски. `000` у curl здесь — не «сайт лёг».
7. **`publication.pravo.gov.ru` живёт по HTTP, а не HTTPS.** `https://` —
   таймаут, `http://` — `200` и 27 911 байт содержимого. `pravo.gov.ru` — так же.
   При этом поиск актов через `/search?q=` отдаёт свежий список публикаций без
   фильтра по запросу: URL открывается, а поиск не работает — это разные факты.
8. **`doi.org/api/handles` иногда обрывается по таймауту** на живом DOI. Повтор
   через несколько секунд обычно даёт `responseCode: 1`; после трёх попыток —
   писать в «Не открылось», а не «DOI не существует».
9. **Europe PMC изредка отвечает HTTP 500 или таймаутом** на исправный запрос
   (за волну 3 — 3 случая из 414). Повтор через несколько секунд проходит;
   `hitCount` в ответе — единственный признак, по которому сверять, а не код
   ответа.
10. **Europe PMC уходит в серию `503` целиком.** В такой серии не отвечает и
    пакетный запрос (40 PMID через `OR`), и одиночный. Обход на это время —
    **NCBI eutils** `esummary.fcgi?db=pubmed&retmode=json&id=<id1,id2,…>`:
    отдаёт `title`, `pubdate`, `journal`, cookie не требует. Сверка по названию
    слабее сверки по `hitCount`, поэтому такой номер помечается в отчёте
    отдельно, а не выдаётся за проверенный Europe PMC.
11. **Пакетная сверка PMID** — 40 номеров в одном запросе
    (`(EXT_ID:1 OR EXT_ID:2 …) AND SRC:MED`, `pageSize=100`): 11 запросов вместо
    414. Вернувшиеся `id` сравнивать с запрошенными; `hitCount` пакета равен
    числу найденных. Одиночный проход по 414 номерам занимает ~40 минут, пакетный —
    ~2 минуты.
12. **`icd.who.int/browse` — JS-приложение**: HTML отдаёт 200, текста критериев в
   нём нет. Тот же ICD-11 читается в печатном MMS-архиве с `icdcdn.who.int`.

## Сколько стоит одна проверка

- 194 идентификатора через Europe PMC: ~4 минуты при 4 параллельных запросах.
- Один DOI через doi.org handle API: ~1 секунда.
- Агент на одну тему (поиск + сверка + файл): ~6 минут.
